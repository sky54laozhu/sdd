## 学习路径建议 / Suggested Learning Path

### 初学者（1-2 周）

1. 阅读本教程系列 Part 1-2（SDD 基础 + Claude Code）
2. 阅读 EARS 原始论文了解需求句法
3. 在一个小项目中实践 CLAUDE.md 宪法模式
4. 观看 Anthropic 官方 Claude Code 视频

### 进阶（2-4 周）

1. 阅读本教程系列 Part 3-4（工作流 + 实战项目）
2. 研究 BMAD-METHOD 的角色分工模型
3. 尝试 Spec Kit 的 drift detection 功能
4. 在团队项目中推广 SDD 实践

### 高级（持续）

1. 阅读本教程系列 Part 5（高级模式）
2. 跟踪学术论文了解前沿研究
3. 贡献开源 SDD 工具
4. 建立团队级 SDD 工作流规范
5. 探索形式化方法与 SDD 的结合
